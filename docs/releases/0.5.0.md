# Codex Process Jobs 0.5.0

Codex Process Jobs now queues App and VS Code completion messages after the owning task becomes idle. On the current Mac client, earlier private IPC and App Server routes did not start a completion turn. The queue route did. A controlled App task and a Mac-local VS Code task each received a normal completion turn without a pending Steer chip.

## User-visible changes

- App and VS Code use `codex queue` in Queue mode after the owning task becomes idle. The CLI queue route remains available.
- The plugin ships one hook, `UserPromptSubmit`. It validates queue completion notices and supplies later-prompt recovery when direct delivery cannot confirm presentation.
- The `PreToolUse`, `PostToolUse`, and `Stop` hook registrations are removed. Codex no longer pauses ordinary local commands for CPJ classification. The start skill retains the launch-turn release instruction.

## Compatibility and reliability

Guarded private IPC and App Server routes remain fallbacks when queue is unavailable. Durable job status and saved output remain available when a client does not render an automatic completion turn. Existing tasks can retain an older cached plugin generation until a new task starts.

The repository suite passed 251/251 tests on the Mac. The CI matrix passed on macOS and Ubuntu with Node.js 18 and 22. The HOL plugin scanner passed. An isolated portable smoke job completed with exit code 0. The packaged file list includes `hooks/hooks.json` and omits the retired PreToolUse script.

The one-hook App canary printed `APP_ONE_HOOK_DONE` and appeared as a normal task turn. Joel confirmed that no Steer chip remained. The earlier desktop queue canaries produced normal App and VS Code completion turns. A separate iOS canary was not run. The Linux execution host was not used for live delivery testing.

## Upgrade

Use the OpenAI Plugins Directory update action. Restart Codex App and CLI, reload VS Code, review the one CPJ hook and its source through `/hooks`, and open a fresh task. Verify that only one CPJ provider is active.
